# Firebase Emulators

Use Firebase emulators when a change needs local Firebase Auth, Firestore, Functions, or Storage behavior.

## One-Time Setup

```bash
npm run emulators:setup
```

This script checks for Firebase CLI and Java, then creates demo-only local config files when they do not already exist. Existing files are skipped by default.

To replace existing local emulator scaffold files:

```bash
npm run emulators:setup -- --force
```

Do this only when you intentionally want to overwrite local demo config.

## Start Emulators

```bash
npm run emulators
```

This builds Firebase Functions and starts the local Firebase services:

- Auth
- Firestore
- Functions
- Storage

## Start the App Against Emulators

In a second terminal:

```bash
npm run dev:emulator
```

The emulator mode uses local Firebase config generated by `npm run emulators:setup`. These files are demo-only scaffolding and should not be deployed to a real Firebase project.

## Emulator Data

Export emulator data:

```bash
npm run emulators:export
```

Start emulators with import/export-on-exit behavior:

```bash
npm run emulators:import
```

## Troubleshooting

If `npm run emulators:setup` reports missing tools, install the Firebase CLI and a Java JDK before running emulators.

If an existing generated file looks wrong, rerun setup with `--force` after confirming you are comfortable replacing the local scaffold.
